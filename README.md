# 월드인포 트래커 0.7.2

지금 응답에 어떤 월드인포가 들어갔는지 보고, 그 자리에서 바로 고칩니다.
고친 내용은 **이 채팅방에만** 적용할 수 있어서, 같은 월드인포를 쓰는 다른 채팅방은 그대로예요.

보기·수정·ON/OFF는 API 없이 동작하고, **AI** 탭에서만 API를 써요.

## 설치

확장 프로그램 → 확장 설치에 아래 주소를 입력합니다.

https://github.com/kkkangkkang-creator/ST-WorldinfoTracker

화면의 📖 아이콘이나 마법봉(🪄) 메뉴의 **월드인포 트래커**로 엽니다.
아이콘 위 숫자는 마지막 응답에 들어간 엔트리 수예요. 채팅방마다 기억해서 새로고침해도 남아 있어요.
아이콘은 끌어서 옮길 수 있고, 확장 설정에서 숨기거나 크기를 바꿀 수 있어요.

## 화면

탭: **이번 응답 · 전체 · 현재 값 · AI · 설정**

**이번 응답** 탭: 마지막 응답에 들어간 엔트리를 책별로 보여줍니다.

- 🔵 상시 · 🟢 키워드 · 🔗 벡터 검색
- 키워드 엔트리는 채팅에서 찾은 키워드를 강조해서 보여줘요. 예: `탑` + 보조 `2층`
- 키워드는 **추정**이에요. SillyTavern이 어떤 키워드로 켜졌는지 알려주지 않아서, 최근 채팅(스캔 깊이)에서 다시 찾아본 결과예요.

**전체** 탭: 이 채팅에 연결된 모든 엔트리. 목록 오른쪽의 **ON/OFF**는 이 채팅에만 적용돼요(노란 테두리 = 이 채팅에서 바꾼 상태).

엔트리를 누르면 수정 창이 열립니다.

## 현재 값 (변수)

층 수, 날짜, 타이머, 랭크처럼 이야기가 진행되면 바뀌는 값은 엔트리 본문에 적지 말고 **변수**로 두세요.
SillyTavern의 채팅 변수를 그대로 쓰니까 **채팅방마다 따로** 갖고, `/setvar` 같은 다른 도구와도 공유돼요.

- 엔트리 본문에 `{{getvar::이름}}`이라고 쓰면 롤플 AI에게는 그 채팅의 값으로 바뀌어 들어가요.
  예: `The floor 2 Break occurs on {{getvar::2층_Break}}.` → `…occurs on 2025/04/22.`
- **이 확장이 관리하는 값만** 보여줘요: 엔트리가 `{{getvar::이름}}`으로 읽는 변수 + 여기서 추가한 변수.
  그 밖의 변수(프리셋 등)는 목록에 나오지 않고, 고치지도 AI에게 보내지도 않아요.
- **현재 값** 탭에서 칸을 고치면 바로 저장돼요 (다음 응답부터 적용). AI는 쓰지 않아요.
- 엔트리에서 쓰는데 이 채팅에 값이 없는 변수는 `⚠ 값이 없는 변수`로 알려줘요.
- 자동 추적·AI가 바꾼 값은 `AI 5분 전 · 1 → 2`처럼 남고, **되돌리기**로 되돌릴 수 있어요.
- 타이머는 "남은 일수" 대신 **Break 날짜**처럼 날짜로 적어두면 갱신할 필요가 거의 없어요.
- 엔트리 수정 창의 **값 뽑기**를 누르면, AI가 그 엔트리에서 바뀔 만한 값을 찾아 변수로 바꾸는 제안을 만들어요 (엔트리당 한 번).

## AI 탭

요청을 적고 **보내기**를 누르면 AI가 엔트리 추가·수정안을 만들어요. **바로 저장되지 않고 제안 카드로 쌓여요.**

- 예: `10층이 클리어되면 균열이 생기는 설정 추가해줘`, `이 엔트리에서 바뀌는 값을 변수로 바꿔줘`
- AI가 보는 것: 관리하는 값(위 기준), 엔트리 목록(제목·키워드), 최근 대화, 그리고 **대상 엔트리의 본문**.
  - **대상**을 고르면(＋ 고르기, 또는 수정 창의 **AI로 고치기**) 그 엔트리 본문만 보내요. 가장 싸고 정확해요.
  - 고르지 않으면 요청에 이름이 나온 엔트리와 이번 응답에 들어간 엔트리를 보내요.
- 수정은 바꿀 부분만 "찾아 바꾸기" 형식으로 받아서 AI 응답이 아주 짧아요. 바뀌는 줄은 빨강(−)/초록(+)으로 보여줘요.
- 카드 버튼: **이 방에 추가 / 이 방에만 적용 / 공용에 적용 / 고쳐서 적용 / 버리기**. 저장 방식은 아래 "수정과 저장"과 같아요.
- 요청이 "2층 클리어됐어"처럼 값이 바뀐 일이면 AI가 현재 값을 바로 바꿔요.
- 제안은 채팅별로 남아 있어서 패널을 닫아도 사라지지 않아요.
- 새 엔트리를 쓸 때 이름·개념을 쉽고 구체적으로 짓는 규칙은 설정 탭의 **추가 지시**에 미리 채워져 있어요. 고치거나 지워도 돼요.

JSON 형식으로 답해야 해서, 작은 RP 모델보다는 지시를 잘 따르는 모델이 잘 맞아요.

## 자동 추적

켜면 대화가 쌓일 때 AI가 월드인포를 확인해요. **설정 탭에서 켜고 주기(턴)를 정해요.** 기본은 꺼짐, 주기는 30턴.
**턴**은 캐릭터 응답 1개예요.

**읽는 방식 (책갈피)**
- 채팅마다 "여기까지 읽었다"는 책갈피를 남기고, 책갈피 뒤로 N턴이 쌓이면 **그 N턴만** 읽어요. 같은 대화를 두 번 읽지 않아요.
- 최신 2턴은 확정될 때까지 기다려요. 스와이프·재생성으로 바뀔 내용을 설정에 넣지 않기 위해서예요.
- **숨긴 메시지도 읽어요.** 요약 확장이 지난 챗을 숨겨도, 어떤 요약 확장을 쓰든 똑같이 동작해요.
- 켠 시점(또는 처음 열어본 채팅)부터 세요. 지난 대화를 한꺼번에 읽지 않아요. 상태줄의 `쌓인 턴 0/22`는 주기 20턴 + 대기 2턴이라는 뜻이에요.
- 메시지를 지워도 책갈피가 따라가요.
- 한 번에 읽을 분량이 길면 여러 덩어리로 나눠서 읽어요.
- 메시지마다 반복되는 `<Status>…</Status>` 같은 블록은 가장 최근 것만 보내요(설정의 상태창 태그).

**찾는 것**
- **값 변화**: 현재 값 중 바뀐 게 있으면 **바로 적용**하고 알림을 띄워요.
- **낡은 정보**: 엔트리가 "아직 ~가 없다"처럼 말하는데 대화에서 달라졌으면 그 문장만 고치는 제안 카드를 만들어요.
- **새 설정**: 앞으로 중요할 새 인물·장소·세력·규칙은 새 엔트리 제안 카드로 만들어요.
- 대화에서 확정된 것만 다뤄요. 계획·소문·추측은 무시해요.

AI 탭의 **지금 확인**을 누르면 주기를 기다리지 않고 마지막 책갈피 이후를 바로 읽어요 (최신 턴도 포함).
책갈피 이후가 비어 있으면(자동 추적을 막 켰을 때 등) 최근 N턴을 읽을지 물어봐요.
이것도 API를 쓰는 기능이라 비용이 나가요. 비용은 읽는 대화 분량에 비례해요.

## 설정 탭

| 항목 | 설명 |
| --- | --- |
| 연결 | 현재 채팅 API, 또는 연결 관리자의 연결 프로필 |
| 생각 | 모델의 생각(추론) 토큰. 기본 **끄기**. 연결 프로필로 요청할 때만 적용돼요. |
| 최근 대화 | AI 탭 요청에 같이 보낼 최근 메시지 수 |
| 최대 토큰 | AI 응답 길이 한도 (기본 16384) |
| 자동 추적 | 켜기/끄기 (기본 꺼짐) |
| 읽는 주기 | 캐릭터 응답 N개마다 한 번 (기본 30) |
| 상태창 태그 | 반복되는 블록을 최신 것만 남길 태그 (기본 `Status`, 비우면 끔) |
| AI 지시문 (고급) | AI에게 보내는 내장 지시문의 **규칙 부분**을 직접 고쳐요. 요청용·자동 추적용 두 개. 아래 "AI 지시문" 참고 |
| 추가 지시 | 매번 같이 보내는 내 규칙. 예: `한국어로 써줘`, `캐릭터 엔트리는 ## BASICS 형식 유지` |

## AI 지시문

AI를 부를 때 확장이 영어 지시문을 맨 앞에 붙여요. 두 개가 있어요: **AI 탭 요청용**, **자동 추적용**.

- **규칙 부분은 수정할 수 있어요.** 설정 탭 → **AI 지시문 (고급)**. 말투, 무엇을 찾을지, 제안 개수 같은 규칙을 단어 하나까지 고칠 수 있어요.
  글자 수가 표시돼요(요청마다 그만큼 토큰이 들어요). **기본값으로**를 누르면 내장 규칙으로 돌아가요.
- **답변 형식(JSON)은 잠겨 있어요.** 규칙 뒤에 항상 붙고, 확장이 이 형식으로 답을 읽어서 카드와 값 변경을 만들어요. **고정 부분 보기**에서 볼 수 있어요. 규칙을 비워도 형식은 남아요.
- 순서: 내 규칙 → 고정 형식 → **추가 지시** (맨 마지막).
- 내장 규칙을 고치지 않았으면 이후 버전의 개선된 기본 규칙이 자동으로 적용돼요. 고쳐둔 경우엔 내 것이 유지돼요.

## 수정과 저장

| 엔트리 위치 | 버튼 | 결과 |
| --- | --- | --- |
| 📘 공용 책 | **이 방에만 저장** | 엔트리를 이 방 전용 책으로 복사해서 고치고, 이 방에서는 원본을 꺼요. 다른 채팅은 원본 그대로. |
| 📘 공용 책 | 공용 책에 저장 | 원본을 고쳐요. 그 책을 쓰는 모든 채팅에 반영돼요. (확인 후 저장) |
| 📗 이 방 전용 책 | 저장 | 그대로 저장. |
| 📗 이 방의 수정본 | 원본으로 되돌리기 | 수정본을 지우고 이 방에서도 원본을 다시 써요. |

- **이 방 전용 책**은 SillyTavern의 채팅 로어북이에요. 이미 연결한 채팅 로어북이 있으면 그걸 쓰고,
  없으면 처음 저장할 때 `이 방 전용 · (채팅 이름)`으로 만들어 연결해요. SillyTavern 월드인포 편집 화면에서도 보여요.
- **찾아 바꾸기**: 본문에서 `two weeks` → `9 days`처럼 같은 표현을 한 번에 바꿔요. 저장해야 반영돼요.
- 수정 창에서 🔵/🟢/🔗 방식, 순서, 발동 확률도 바꿀 수 있어요. 저장 버튼은 항상 화면 아래에 보여요.
- **＋ 새 엔트리**: 이 방 전용 책에 새 엔트리를 추가해요.
- 고친 내용은 **다음 응답부터** 적용돼요. 응답 생성 중에는 저장할 수 없어요.
- 저장할 때마다 직전 내용을 이 브라우저에 보관해요. 수정 창의 **저장 전 내용 불러오기**로 되돌릴 수 있어요.

### 알아두기

- 수정본은 복사한 순간의 ON/OFF를 따라가요.
- 이 방 전용 책에서 수정본을 직접 지우면, 이 방에서도 원본이 다시 들어가요.
